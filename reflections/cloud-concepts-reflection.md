Guide Questions
1. Cloud Services I Use: List at least 3 cloud services or applications you use regularly (e.g. Google Drive, Netflix, Messenger, Canva, GCash).
2. Identify the Models: For each service you listed, identify its service model (IaaS / PaaS / SaaS) and deployment model (Public / Private / Hybrid / Community). Briefly explain why you chose that classification.
3. Git & GitHub for Cloud Projects: Explain why version control is critical when working with cloud infrastructure. How does GitHub help teams collaborate, track changes, and prevent errors when managing cloud resources?

I use cloud services almost every day sometimes without even realizing they are cloud-based. The three cloud services I use regularly are Google Drive, Canva and Messenger. These apps help me in my school activities, communication and in storing important files.

Google Drive is Software as a Service ( SaaS ) because I can use it directly over the internet to store and manage my files without having to manage the servers . It also uses a Public Cloud model as it is available online to many users. Canva is also a SaaS, I can create presentations, posters and other school projects with its online tools. It is a Public Cloud because I can access it from the internet using different devices. Another example of SaaS is Messenger, as I can use it for messaging and communication without installing or managing the servers behind the application. It is also using a Public Cloud deployment model, as its services are delivered online to many users.

I also learned that Git and GitHub are good tools for cloud projects. As a student sometimes i make mistakes when editing files or working on programming projects. Git allows me to keep track of the changes I make and go back to an older version if I need to. And it’s easier to store my projects online and access them on different devices thanks to GitHub.
